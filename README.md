# earmark

Записывает созвоны и раскладывает записи по папкам календарей. Как Anarlog, только без мишуры: запись и раскладка, больше ничего.

- Запись стартует сама, когда начинается встреча из подключённого календаря, или вручную.
- Каждая запись ложится в папку своего календаря.

Статус: идея, кода пока нет.
